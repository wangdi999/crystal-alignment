# 共鸣远征：设计依据与边界

## 参考与转化

用户选择「随机增益＋局内成长」，目标是提升重复游玩。2026-10-16 检索参考了 [Balatro 商店对 Joker 协同与种子局的描述](https://store.steampowered.com/app/2379780/Balatro/) 和 [Blue Prince 的房间探索与重复游玩结构](https://store.steampowered.com/app/1569580/Blue_Prince/)。商店用户评价显示两者受玩家认可，不能据此认定某个元素单独造成成功。

本作转化为「每颗晶核首次归位充能，主动技能改变空间站位，协议放大归位与技能后的收益」。玩家选成长时，能改变后续解谜的操作手段。

## 循环与随机性

起手技能三选一 → 预览棋盘、选择稳态／过载 → 解谜 → 确认结算 → 成长三选一。共四房、四协议。开局保证牵引、相位、脉冲可选，后续从未获得协议中抽三项。

九个手工模板分四层抽取，再旋转或镜像，全部模板的八种变换均校验可解。对称变换不增加空间拓扑，本版没有无限随机地图。相同种子与选择可确定性重放，操作顺序与刷新不重抽成长。

## 资源与得分

| 项目 | 数值 | 目的 |
| --- | --- | --- |
| 初始稳定度 / 上限 | 80 / 100 | 允许观察与试错，保留长路线压力 |
| 初始电荷 / 常规上限 | 4 / 8 | 第一房可体验技能，之后用归位补充 |
| 普通操作 / 技能操作 | 成功后消耗 1 稳定度 | 时间不扣资源，可以停下来思考 |
| 技能电荷 | 牵引 2、相位 2、脉冲 3 | 远程改变晶核位置收费更高 |
| 首次归位 | 每颗每房 +1 电荷、+12 分 | 将解谜进展变为技能资源，禁止重复归位刷取 |
| 房间完成 | 恢复 20 稳定度 | 提供分房间的续航节点 |
| 稳态路线 | 入场 +2 电荷 | 基准体验 |
| 过载路线 | 入场 +3 电荷、通关 +50 分；普通推动额外扣 1 稳定度 | 更高资源和得分，同时考验效率 |

通关分：`max(20, 80 + 层数索引 × 20 - 本房操作数) + 路线额外分`。首次归位、回声分单独累计。失败技能不扣资源；回收在成功施放后返还，必须先支付完整费用。最后一步归位时可以先得到通关恢复。

## 协同

| 成长协议 | 效果 |
| --- | --- |
| 超导绕组 | 首次归位额外 +2 电荷，上限 10 |
| 回收外壳 | 成功技能返还 1 电荷 |
| 生长晶簇 | 首次归位恢复 5 稳定度 |
| 精密齿轮 | 每房前 3 次普通推动免基础消耗，保留过载附加消耗 |
| 余辉晶壳 | 通关时每点余电额外恢复 2 稳定度，电荷保留 |
| 回声发生器 | 技能后的下一次普通推动 +1 电荷、+10 分；每颗晶核每房一次 |

例：相位换位 → 普通推动触发回声 → 归位通过超导充能 → 回收降低下一次技能净成本。首次归位与回声均按晶核身份记录，循环拉推同一颗不会重复结算。

## 撤销、存档与提示

存档记录种子与合法事件，不接收外部坐标。刷新时重放协议、路线、移动、技能与结算；非法记录回到合法起点。撤销与重做恢复一次性奖励标记及全部资源。确认下一房后锁定当前结算。

提示搜索考虑技能、电荷、稳定度和协议；达到上限时说明暂未找到路线，避免误报无解。经典模式的静态死位判断不用于远征，因为牵引可以救回部分经典死位。

每日种子按北京时间日期生成。挑战链接只分享种子，成绩留在本机，没有线上排名或防作弊承诺。

## 待真人验证

自动化包含全部模板变换、资源约束、60 次四房间合法通关和浏览器实际操作。尚无真人数据。下一轮应观察技能选方向是否易懂、过载是否有吸引力、是否存在必选协议，以及相同种子换构筑是否产生新的路线。模板重复感、稳定度容错和技能价格都可能需要根据试玩调整。
